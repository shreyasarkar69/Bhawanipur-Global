BHawanipur Global Campus - Campus Connect Event Management System
====================================================================

INSTALLATION
1. Extract this ZIP.
2. Copy the event_management_system folder into C:\xampp\htdocs\
3. Start Apache and MySQL in XAMPP.
4. Open http://localhost/phpmyadmin/
5. Import database.sql (if you already imported it earlier, you do not need to import again unless resetting your database).
6. Open http://localhost/event_management_system/

DESIGN UPDATE
- Campus Connect homepage themed around Bhawanipur Global Campus colours.
- Added the uploaded BGC logo and campus-building photo in assets/.
- Added responsive event cards, campus images, hover effects, entrance animations, floating cards, and mobile-friendly layout.
- Event cards choose an image based on event title; the stock images require an internet connection.
- Google Fonts also require an internet connection. The site falls back to standard fonts if offline.

IMPORTANT
This is a student project design, not an official campus website. Confirm permission before presenting it as an official institutional site.
